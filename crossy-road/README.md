# Crossy Road

## About the Game

Simple remake of the crossy road game

## How to Play

- Use W / Up Arrow to move forward
- Use S / Down Arrow to move backward
- Use A / Left Arrow to move left
- Use D / Right Arrow to move right
- Avoid moving vehicles and other hazards
- Your score increases as you reach new forward lanes
- Moving backward does not reduce your score
- If you are hit by a vehicle, the game ends
- Press Enter or Space to restart

## AI Tools and Models Used

I used:
- Kiro with Auto model selection
- ChatGPT
- Codex in VS Code

## Development Strategy

I started by getting the core gameplay loop working first: player movement, lanes, cars, collision detection, scoring, and restarting. After the gameplay worked, I improved the visuals into a 2.5D style, added directional chicken animations, environmental detail, and then used targeted prompts to fix specific bugs and polish the final game.
